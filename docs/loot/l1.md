## L1 scope and remaining limits

Eight bases/eight affixes/two named unique templates are an extensible foundation, not a production item catalog. Level requirements are validated data/inspection metadata; no equipment/stat application, level progression, inventory/grid, collection, comparisons, vendors, crafting, sockets/runewords or set system. Identification is an explicit free prototype transition, not a scroll/economy system. Items remain on ground until trial reset or explicit archive replacement; world capacity128, up to32 nonoverlapping visible labels, all drops selectable. Capacity/placement rejection is counted, not silently presented as successful spawning.

Item archive schema1/content2 is a bounded developer persistence foundation, not an encounter/player/world save or anti-cheat. Old content1 prototypes are rejected rather than rerolled; migration remains outside L1. Original procedural marker/label/tier synthesis presentation has no new texture/audio download; detailed item icons/art and prior provisional monster sprites remain open. Physical Xbox/PlayStation/vibration/disconnect/real latency tasks DBL-282–286 are unverified; browser checks emulate standard mappings.
