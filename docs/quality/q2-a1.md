## Implementation

- Original top-right enter/exit SVG button requests fullscreen on the main game
  container directly from a click. HUD and overlays remain inside; controller
  menu/widget now share the game container. No new keyboard mapping.
- Fullscreen change reuses current renderer resize handlers and restores world
  focus when no dialog is open. Escape fallback does not consume cancel events;
  an open dialog retains first cancellation. Native browser Escape still works.
- Unsupported API is visibly disabled; denial/error gives status feedback.
  Abortable listeners are removed on pagehide and restored for bfcache pageshow.
- Capturing contextmenu cancellation covers only the playable main container,
  including canvas, loot labels and sibling overlays. No document-wide handler;
  pointer/click/cast/inspection events remain intact and outside menus stay native.
- Corrected both FIT renderers to use Phaser's setGameSize rather than resize:
  the old call retained a16:10 CSS ratio over an868x600 buffer at1100x760.
  Matching buffer/display ratios now preserve proportions and pointer projection.
